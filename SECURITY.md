# Security

A skill is a set of instructions your agent loads and follows. A
harmful change to a skill acts like a prompt injection in every agent
that installs it. Report a problem privately, not in a public issue.

Use **Security → Report a vulnerability** on this repo. That opens a
private advisory only the maintainer can see.

Report, for example, a skill that tells an agent to run, send, publish
or delete something its description does not cover. Include the skill,
the agent you used, and what it did. Never include a token or private
key, even an expired one.

Before you install, read the `SKILL.md` of each skill you add. To stay
on a version you have read, copy the folder from a commit or tag rather
than tracking `main`.
